# bd1-redsocial-grupoCS
S1. Tarea. Modelo conceptual de la red social estudiantil Pascualina
Integrantes: Camila Andrea Ortiz Gómez - Sonia Maria Gomez Bolivar

Este proyecto consiste en el diseño del modelo conceptual de una base de datos para la Red Social Pascualina, una plataforma orientada a mejorar la comunicación e interacción entre los estudiantes.

La red social permitirá a los estudiantes crear perfiles, compartir intereses y habilidades, conectarse con otros compañeros, realizar publicaciones, participar en grupos de estudio o interés y organizar eventos académicos o sociales.

Como parte de la propuesta de solución, se diseñó un Modelo Entidad-Relación (MER) en el que se identificaron las principales entidades, sus atributos, relaciones y cardinalidades necesarias para representar el funcionamiento de la plataforma.
